# TIMBERMAN 2D (Vue 3 + Three.js)

2D-версия классической аркадной игры **Timberman**, реализованная на **Vue 3** (`<script setup>`, Composition API) и **Three.js** (`OrthographicCamera`) с процедурной 2D-графикой, Web Audio API звуками и адаптивным интерфейсом для ПК и мобильных устройств.

## Возможности

- **Vue 3 интерфейс**: компонентная архитектура (`GameHud`, `StartScreen`, `GameOverScreen`, `LevelBanner`, `TapHints`) и реактивный composable `useTimberGame` с корректной очисткой ресурсов и подписок.

- **Three.js 2D-движок**: ортографическая камера, многослойный параллакс-лес, динамическая смена времени суток (день → закат → ночь со звёздами), физика разлетающихся поленьев, щепок и листьев, тряска камеры.
- **Честная генерация веток**: противоположные ветки всегда разделены безопасным сегментом без ветки.
- **4 героя**: Дровосек, Викинг, Ниндзя и Гризли с процедурными спрайтами (`idle` / `chop`) и классическим надгробием `R.I.P.` при проигрыше.
- **Прогрессия и рекорды**: таймер-шкала, повышение уровня каждые 20 ударов, счётчик комбо, удары/сек (CPS) и сохранение рекорда в `localStorage`.
- **Звук без внешних файлов**: синтезатор звуковых эффектов на Web Audio API с кнопкой отключения звука.
- **Управление**: клавиши `←` / `→` или `A` / `D`, либо клик / тап по левой / правой половине экрана; `Space` / `Enter` для быстрого рестарта.

## Запуск

```bash
npm install
npm run dev
```

## Сборка для продакшена

```bash
npm run build

```
